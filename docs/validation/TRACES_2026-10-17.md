## Executed vs unit-tested

* Runtime-executed (real code paths on generated files): every importer through
  its Python entry point; the CLI (`import-trace`, `traces-kinds`,
  `traces-summary`, `traces-geotags`) through `cli.main`; HTTP upload and
  `EW_SCAN_ROOTS` path imports, listings and the `/traces` page through the
  FastAPI test client; catalog scan → import plan → approval → execution for
  sidecars, images (`photo_geotags` alternative), all six messaging formats,
  account activity, documents, Keep and a browser profile; the `/traces` page in
  real Chromium (navigation label, counts, escaping of a markup-like export label,
  absence of third-party names and coordinates, no page errors).
* Hard cases covered by tests: truncated 51/47-character Takeout names,
  `(1)` duplicates, NFD file names vs NFC titles, ambiguous cut prefixes, edited
  copies, missing sidecars/media, album `metadata.json`, `0,0` geo placeholders,
  contradicting `geoData`/`geoDataExif`, negative (pre-1970) and
  millisecond-in-seconds timestamps, EXIF GPS in the southern/western hemisphere
  below sea level, a GPS block without hemisphere reference, PNG `eXIf`, HEIC;
  Facebook mojibake (decoded, already-proper text above U+00FF, invalid
  sequences, lone surrogates, RTL/emoji), identical repeated messages, unknown
  types, non-object records, E2EE JSON; Telegram local `date` vs `date_unixtime`,
  edits, entity text, omitted files, shared locations, ms-as-s; Google Chat
  localized/abbreviated/numeric zones; X `window.YTD` prefix missing, `+0530`
  offsets; LinkedIn quoted multi-line HTML cells, short rows; login records with
  IPv4/IPv6/invalid IPs, cookies, provider locations, `label_values`,
  `string_map_data`, Google CSVs; PDF partial dates, `Z00'00'`, missing `D:`,
  `+25'00'`/`+01'99'` offsets, month 13, incremental updates, object streams,
  XMP vs Info contradictions, encrypted strings, no Info; corrupt OOXML, a
  zip-bomb-shaped member, DOCTYPE/ENTITY, OLE; Keep µs fields holding ms, trashed
  notes; Chromium WebKit epoch zero/overflow/unix-µs, a committed visit present
  only in the WAL (read from the copied pair; immutable copy without it),
  Firefox PRTime with an embed and ms-in-µs, a non-browser SQLite file.
* Originals: every test compares SHA-256 of the generated inputs before and
  after; the browser test also compares mtimes and checks that no `-shm` file
  appears next to the profile.
* Not run: real vendor exports (none available), real devices, HEIC/MP4
  metadata, network calls of any kind (none exist in these code paths).

## Boundaries

* Layouts follow public observations and are encoded in versioned data files;
  they were not checked against real downloads.
* Import plans read a browser profile's main database only (its `-wal` is a
  separate catalog entry); the CLI on the profile folder reads the WAL.
* `iter_geotags()` is a read contract for the location area; place matching is
  not implemented here.
