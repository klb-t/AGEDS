**Runtime-executed:**

- All five report types were generated from synthetic corpus parts:
  `chat_exports`, `communications` and `catalog_files` (two catalog scans).
  Planted hard cases: HTML in source text, formula-like text, a control
  character, unknown zone, an untimed call, word/segment citations, and a
  legacy NaN timing.
- Each HTML file was parsed and every value was compared with `report.json`;
  no numeral appears outside value spans.
- Real CLI subprocesses ran, including refusals. `report-verify` ran without a
  database or configuration import. The standalone bundle consumer ran with
  `python -I`.
- Headless Chromium printed a PDF. openpyxl wrote XLSX with forced string
  cells.
- Real Chromium exercised `/reports`: sandboxed preview without script
  execution, a downloaded file hash equal to the manifest entry, and tamper
  detection.
- A metadata package with `extension_tables` was exported, validated, checked
  for tamper detection and round-tripped byte-exactly through the archive.
- Scale probe with 20,000 synthetic events: generation 4.3 s, verification
  0.3 s, 149 MB maximum RSS.

**Unit-tested only:**

- provider override hook;
- the generic adapter for upstream dicts;
- refusal of numerals in model prose. No model prose exists.

**Not run:**

- real C, E1 and E2 outputs (modules absent; the sections are explicitly
  unavailable or use the source-seam fallback);
- any model or LLM call;
- Android.

Boundaries: digests are not signatures. A report reflects the listed input rows
at generation time. Upstream catalog and dedup functions read in their own
transactions, and each section records this. CSV text is formula-guarded;
exact values are kept in JSON, HTML and XLSX.
